# Gesture AI Exhibition

A live hand-gesture recognition demo for the exhibition. Show a hand to the camera and the page names the gesture on screen.

## Live link

https://ashik-mangalan.github.io/gesture-ai-exhibition/

Open it on a phone, tablet or laptop, press **Start camera & AI**, and allow camera access.

## Gestures it recognizes

- Open palm
- Victory (peace sign)
- Thumbs up
- Thumbs down
- Pointing up
- Closed fist
- Love sign (I love you)

## Notes

- Needs an internet connection to load the AI model.
- Works only on HTTPS, which GitHub Pages provides.
- Camera video is processed in the browser and is not uploaded.
